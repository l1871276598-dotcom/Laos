LAOS.

本地优先、可审计、人工审核的 AI 记忆层

Local-first, auditable, human-governed memory and learning layer for AI agents.

LAOS 把结构化记忆、项目上下文、任务结果、反思和可复用原则，统一存放在你自己控制的本地文件与可重建索引里，供 GPT、Codex、Claude、本地模型和其他 Agent 复用——复用之前，先过人工审核。

在 GitHub 上查看 LAOS 读 README

为什么是 LAOS

  • 本地所有：权威记忆留在你自己控制的文件里，派生索引可以重建，不依赖外部服务。
  • 人工审核：Agent 只能创建候选记忆（candidate），只有明确的 Review Gate 决定才能接受为正式记忆。
  • 可审计：记忆与学习产物保留可追溯的来源证据和确定性处理路径。
  • 模型无关：GPT、Codex、Claude、本地模型共用同一套受控知识层。

现在能做的事（v0.14.0）

  • Memory Core：Markdown / JSONL 权威数据源 + 单文件 SQLite，零外部服务依赖。
  • 混合检索：sqlite-vec 原生向量扩展，BM25 + 向量 RRF 混合打分。
  • 统一 12 Agent JSON CLI：导入、记忆、搜索、审核、上下文、反思、策略、循环协调等。
  • 确定性学习链：finalize → 反思 → 建议策略 → 生成候选 → Review Gate。
  • MCP 接入：通过 FastMCP 向 Claude Code / Cursor / Antigravity 提供本地 Agent 能力。

诚实边界

  • 不自动批准任何候选记忆，不自动修改提示词、代码或行为。
  • 没有浏览器侧被动采集，没有无人值守后台重试，没有多用户认证。
  • 没有 GUI、Web 前端或桌面应用；当前验收平台是 macOS，运行在本地、可信操作者边界内。

一句话：好用，但不完美——能用的地方说清楚，不能的地方也不藏着。
